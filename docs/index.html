🔍 Oracle Analysis

First mining pool enabling Scrypt (LTC/DOGE) miners to join Bittensor via merged mining. Dual reward system — miners earn both LTC/DOGE from mining AND alpha tokens from Bittensor validation. Open-source with Docker support and AWS backend. Only subnet in the top 10 with real TAO emission inflow — the root network literally pays this subnet.

Bull Case

  • LTC/DOGE hashrate is enormous — 1% capture = transformative
  • TAO inflow proves validators see real economic value
  • Dual rewards: miners earn LTC/DOGE + alpha simultaneously
  • LTC halvening (Aug 2027) will drive miners to alternatives

Bear Case

  • Centralized AWS proxy = single point of failure
  • Manual withdrawal is custodial (1-3 days)
  • LTC/DOGE price collapse eliminates miner incentive
  • Competition from InfiniteHash (BTC mining pool)
