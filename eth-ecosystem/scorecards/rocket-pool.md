## 🔍 TruthSeeker — 7/10

**What It Does:** Rocket Pool is the only truly decentralized liquid staking protocol on Ethereum. Unlike Lido (which uses a permissioned set of node operators), Rocket Pool allows anyone to run a validator with just 8 ETH (vs. 32 ETH solo). Users stake ETH → receive rETH, which accrues staking yield. Node operators deposit RPL as collateral to earn extra rewards.

**Comparable to:** The "people's Lido" — decentralized, permissionless, and community-owned.

**Fundamental Analyst Notes:**
- Rocket Pool's node operator set is the most decentralized of any LST protocol
- The 8 ETH minimum (vs. 32 ETH solo) democratizes validator operation
- RPL collateral requirement aligns node operators with protocol health
- rETH is accepted as collateral in Aave, Maker, and other DeFi protocols
- The protocol has never been exploited — strong security track record
